# EduPlatform — Вебсервіс підтримки навчального процесу з інтеграцією AI-агента

> Сучасна освітня платформа (LMS) з інтегрованими модулями штучного інтелекту для автоматичної генерації структури курсів викладачам та контекстної допомоги студентам під час уроків.

## Загальна інформація

- **Тип проєкту**: Вебплатформа (Learning Management System, LMS)
- **Backend**: Python 3.10+, FastAPI, Pydantic, Uvicorn
- **Frontend**: JavaScript, Vue.js 3 (Composition API), Tailwind CSS, Lucide Icons
- **База даних**: NoSQL MongoDB
- **Інтеграція з ШІ**: OpenAI API (генеративні моделі GPT для аналізу контексту та генерації відповідей)


## Функціональні можливості системи

### Безпека та Доступ
- Реєстрація та автентифікація користувачів з криптографічним хешуванням паролів (бібліотека `passlib` з алгоритмом `bcrypt`).
- Рольова модель доступу: чітке розмежування інтерфейсів та прав для **Викладачів** та **Студентів**.
- Управління сесіями на основі рольової моделі: Після успішної перевірки автентифікації дані користувача (ID, ім'я та роль) передаються на фронтенд для динамічного керування інтерфейсом.

### Кабінет Викладача (Панель управління)
- Створення нових навчальних курсів та керування темами уроків.
- **AI-генерація курсів**: можливість автоматично створити детальну структуру модулів та уроків на основі завантаженого або введеного опису (силабусу) дисципліни.
- Наповнення уроків теоретичним контентом та практичними завданнями.

### Кабінет Студента (Простір навчання)
- Зручний перегляд списку доступних курсів та інтерактивне проходження занять.
- **Контекстний AI-асистент**: вбудований у вікно уроку чат-бот, який аналізує поточну тему заняття, теоретичний опис та інструкцію до практичного завдання.
- Допомога у навчанні: ШІ-асистент налаштований діяти як ментор (надає підказки, алгоритми та теоретичні роз'яснення), не вирішуючи завдання повністю замість студента (захист академічної доброчесності).

### Як запустити проєкт "з нуля"

### 1. Встановлення інструментів

    - Python (версії 3.10 або вище) Перевірте наявність інструменту командою 

      ```bash
      python --version. 
      ```
    Якщо утиліту не встановлено, завантажте відповідний дистрибутив для вашої ОС. (https://docs.python.org/3/using/index.html)

    - Node.js (разом із менеджером пакетів npm) Необхідний для збирання фронтенд-частини проєкту. Перевірте встановлення командами 
    ```bash
    node -v та npm -v.
    ```
    (https://docs.npmjs.com/downloading-and-installing-node-js-and-npm)

    - MongoDB (локальний сервер через MongoDB Compass)
    Система потребує запущеного екземпляра СУБД. Рекомендується встановити локальну версію MongoDB Community Server разом із MongoDB Compass для візуального контролю документів.
    https://www.google.com/search?q=https://www.mongodb.com/docs/manual/administration/install-community/


### 2. Клонування репозиторію

Якщо ви завантажили архів з Moodle, просто розпакуйте його. Якщо ви працюєте через Git, виконайте:

```bash
git clone [https://github.com/kattriinaa/EduPlatform.git](https://github.com/kattriinaa/EduPlatform)
cd EduPlatform
```

### 3. Налаштування змінних оточення

Створіть файл `.env` у папці `backend/` із наступними змінними:

```
MONGO_DETAILS=mongodb://localhost:27017
OPENAI_API_KEY=your_openai_api_key_here
```

### 4. Встановлення залежностей та Запуск

### Backend (FastAPI)

Відкрийте термінал у папці `backend/` та виконайте команди:

```bash
cd backend    
pip install -r Requirements.txt
uvicorn main:app --reload
```

Бекенд буде доступний за адресою: http://127.0.0.1:8000, а документація API за посиланням http://127.0.0.1:8000/docs.

### Frontend (Vue.js)

Відкрийте окремий термінал у папці frontend/ та виконайте команди:

```bash
cd frontend
npm install
npm run dev
```

Клієнтський інтерфейс буде запущено за адресою: http://localhost:5173.

### API приклади

### Автентифікація

**POST /api/register**

```json
{
  "name": "User Name",
  "email": "email@gmail.com",
  "password": "securepassword123",
  "role": "student"
}
```

**Response:**

```json
{
  "id": 1,
  "name": "User Name",
  "role": "student",
  "email": "email@gmail.com"
}
```

**POST /api/login**

```json
{
  "email": "email@gmail.com",
  "password": "securepassword123"
}
```

**Response:**

```json
{
  "message": "Login successful",
  "id": 1,
  "name": "User Name",
  "role": "student",
  "email": "email@gmail.com"
}
```

### Інтелектуальний помічник

**POST /api/ai/chat**

```json
  "messages": [

      "content": "Допоможи розібратися з асинхронністю в Python."
```

```json
}
```

### Інструкція для користувача

**Головна сторінка — вибір дії та авторизація:**
    - Увійти — вхід за допомогою email та зашифрованого паролю.
    - Зареєструватись — створення акаунту студента або викладача.

**Простір викладача:**
    - Кнопка ➕ Створити курс — ручне заповнення розділів та уроків.
    - Кнопка AI-генерація — швидка автоматична генерація контенту на базі введеного силабусу дисципліни.
    - Меню перевірки — надання оцінок та текстових підказок-фідбеків надісланим завданням.

**Простір студента:**
    - Перегляд переліку занять та розкладу в інтерактивному календарі.
    - Натискання кнопки 🤖 Edu Assistant у кутку уроку викликає AI-асистента, який підтримує навчання відповідно до поточної теми.
